# 曼荼羅目標管理テンプレート インストーラ

Notion の OAuth テンプレート複製機能を使って、曼荼羅目標管理テンプレートを
**別ワークスペースの人に配る**ための最小アプリ。

テンプレートは中心＋8マスで人生の領域を決め、そこに目標をぶら下げ、日々の Todo まで一本で繋げる構成。

## 仕組み

複製はこのアプリがやるのではなく、**Notion が認可時に実行する**。

```
利用者がボタンを押す
  → Notion の認可画面（「テンプレートを複製」を選択）
  → Notion が利用者のワークスペースにテンプレートを複製
  → /callback に code が返る
  → code をトークンに交換し duplicated_template_id（複製先ページID）を取得
  → 複製されたページへリダイレクト
```

アクセストークンは**保存していない**。複製先ページへ案内するためだけに使い、そのまま捨てる。
他人のワークスペースの資格情報を持たない設計。

## セットアップ

### 1. テンプレートページを公開する（Notion 上の手作業）

配布元のテンプレートページで:

1. 右上「共有」→「Web で公開」をON
2. **「複製を許可」をON**（これがないと複製できない）
3. 公開URLを控える

> ⚠️ この設定は API から変更できないため、必ず手作業で行う。

### 2. パブリックインテグレーションを作る（Notion 上の手作業）

<https://www.notion.so/my-integrations> で:

1. 新規インテグレーションを作成
2. 種別を **Public** にする
3. **Redirect URI** に `https://<デプロイ先ドメイン>/callback` を登録
4. **「Template」欄に手順1の公開URLを登録** ← これが複製機能の本体
5. 発行された **Client ID / Client secret** を控える

### 3. 環境変数

`.env.example` を `.env.local` にコピーして埋める。

| 変数 | 中身 |
| --- | --- |
| `NOTION_CLIENT_ID` | インテグレーションの Client ID |
| `NOTION_CLIENT_SECRET` | Client secret |
| `NOTION_REDIRECT_URI` | 手順2の Redirect URI と**完全一致**させる |

Redirect URI が1文字でもズレると認可が通らない。

### 4. 起動

```bash
npm install
npm run dev
```

## デプロイ

Vercel の場合、環境変数3つを設定してデプロイするだけ。
デプロイ後のドメインが確定したら、**手順2の Redirect URI と `NOTION_REDIRECT_URI` の両方**を
実際のドメインに直すこと。

## 動作確認

別ワークスペース（または個人の別アカウント）でトップページを開き、
「Notion に追加する」→ 認可画面で複製を選ぶ → 複製されたページに着地すれば成功。

確認すべき点:

- 3つのDB（⛳ テーマ / 🧭 目標 / 🪧 Todo）が揃っている
- **目標DBの「テーマ」リレーションが、複製先のテーマDBを指している**（元のワークスペースを参照していない）
- ⛳ テーマに9行の空枠が入っている

## テンプレートを更新したとき

Notion 側のテンプレートページを編集すれば、**以降に複製する人には新版が入る**。
すでに複製した人のページは変わらない（Notion の複製は一度きりのコピー）。
